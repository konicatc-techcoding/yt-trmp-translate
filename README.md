# yt-trmp-translate

## Claude Code Agents

### 專業廚師（professional-chef）

位置：`.claude/agents/professional-chef.md`

在此 repo 中使用 Claude Code 時，只要提供料理的**圖片**或**文字敘述**，
專業廚師 agent 就會自動辨識菜色，並說明：

- 📋 食譜：食材與份量、前置處理、逐步作法（含火候與時間）
- ⚠️ 注意事項：關鍵失敗點、食品安全、常見錯誤與補救、替代食材
- 💡 主廚小提示

也可以明確指定呼叫，例如：

```
用 professional-chef 幫我看這張照片是什麼菜，並教我怎麼做
```
